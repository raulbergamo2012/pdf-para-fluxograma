Como instalar jogos no console

Existem três métodos para instalar um jogo: pelo disco, pela loja digital ou pelo download remoto.

1. Instalação pelo disco
1.1 Insira um disco compatível na unidade do console.
1.2 O console inicia a instalação dos dados automaticamente.
1.3 Mantenha o disco na unidade para jogar.

2. Instalação pela loja digital
2.1 Acesse a loja no menu principal.
2.2 Se necessário, adquira o jogo.
2.3 Selecione Baixar.

3. Download remoto
3.1 Abra o aplicativo no celular.
3.2 Selecione o jogo na biblioteca.
3.3 Toque em Baixar no console.
3.4 O console precisa estar no modo de repouso e conectado à internet.

4. Concluir a instalação
4.1 Aguarde a instalação.
4.2 Verifique se a instalação foi concluída.
4.3 Se a instalação foi concluída, o jogo aparece na tela inicial.
4.4 Se a instalação não foi concluída, verifique o erro e siga o procedimento de solução de problemas.

Dicas
- É recomendado manter o console atualizado.
- Você pode mover jogos para um armazenamento estendido para liberar espaço.

Solução de problemas
- Se não houver espaço suficiente, exclua jogos que não utiliza.
- Se o download estiver lento, conecte o console por cabo de rede.
